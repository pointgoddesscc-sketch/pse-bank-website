# PS&E Bank Website

Professional marketing website for **PS&E Bank** — private banking & wealth platform.

**Live:** https://pse-bank-website.vercel.app  
**App:** https://pse-wealth-platform.vercel.app  
**Compliance:** https://github.com/pointgoddesscc-sketch/pse-bank-license-compliance

## Stack

- Next.js 15 + React 19 + TypeScript
- lucide-react icons
- Deployed on **Vercel**

## Features on this site

- Private accounts & multi-user positioning
- Instant transfers
- Cards & payments / Stripe top-ups
- Wealth & crypto product narrative
- Security & compliance links
- Live support CTA
- Full footer legal/compliance framing

## Local

```bash
npm install
npm run dev
```
